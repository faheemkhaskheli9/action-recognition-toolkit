Detect + track people in raw video

View past runs →

For raw footage with more than one person in frame — a restaurant, warehouse, retail floor, anything. Skip this and go straight to Label if your clips already have one person each.

How this works
  1. Detect — every frame of every video in the chosen dataset (or just the one video you pick below) is scanned for people.
  2. Track — detections are linked across frames into one track per person, so the same person keeps one identity as they move through the shot.
  3. Crop — each track is cut into short, overlapping time windows and cropped to that person, written as one clip file per person per window under data/tracks/<name>/.
  4. Import — once the run finishes, its detail page has an "Import clips into dataset" button that copies the clips back into a dataset (the source dataset by default), where Label and Dataset read/write. (Or run ar-build-manifest straight against data/tracks/<name>/ from the CLI instead.) From there, label and train as usual.
