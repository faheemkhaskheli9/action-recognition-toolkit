How this works

Training a custom action-recognition model, start to finish:

  1. Raw footage with more than one person in frame (a restaurant, warehouse, retail floor, anything)? Upload it to a dataset here, then run Extract tracks — it detects and tracks every person and crops one clip per tracked person into data/tracks/<video>/, either for every video in the dataset or just one you pick. Once the run finishes, use its "Import clips into dataset" button to copy the extracted clips back into a dataset before labeling (or run ar-build-manifest straight against the data/tracks/<video>/ folder from the CLI instead). Already have clips trimmed to one person each? Skip straight to labeling.
  2. Label every clip with whatever action taxonomy fits your scenario (staff tasks, customer behavior, anything you define) — upload and label right here on this page, or use the Label page to go through unlabeled clips one at a time. Got a longer recording where the action is only part of it? The Label page also lets you mark one or more labeled spans (a start/end time) instead of labeling the whole file at once.
  3. Review manifest any time to fix or delete labels you've already saved.
  4. Train a model once you've got labeled clips across at least two classes.
  5. Inference a finished checkpoint on a new video — tick "scene mode" if that video also has multiple people, to get a separate prediction per tracked person instead of one label for the whole clip.

Upload videos, see what's in your dataset, and fix labels — all in one place. Prefer labeling one at a time? Use the Label page.
